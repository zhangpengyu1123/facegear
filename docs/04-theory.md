# 04 · 计算理论与公式出处

> 本文档记录 `facegear` 每个计算步骤所用的公式、符号含义与**确切出处**，
> 供审阅与二次开发。所有公式均在代码 docstring 中重复标注。

---

## 1. 总体技术路线

面齿轮的齿面由**插齿刀**（gear shaper cutter）按展成法加工得到，其周向齿形
是渐开线，因此可以等效为「齿数 = z2 的直齿圆柱齿轮」。基于这一等价性，
强度计算走**当量齿轮法**：

```
面齿轮几何参数 ──► 当量直齿圆柱齿轮副 (z1, z2)
                        │
                        ├─► ISO 6336-2 ──► 接触应力 σH
                        └─► ISO 6336-3 ──► 弯曲应力 σF
                        │
                        └─► 与许用应力比较 ──► 安全系数 S_H, S_F
```

三条并行引擎：

| 引擎 | 方法 | 代码位置 | 用途 |
|---|---|---|---|
| A（主） | ISO 6336 当量齿轮法 | `stress.py: contact_stress_iso6336 / bending_stress_iso6336` | 设计计算 |
| B | Hertz 点接触 + 面齿轮曲率 | `stress.py: contact_stress_hertz` | 上限参考 |
| C | 何飞(2023) 简化公式 | `stress.py: hefei_simplified` | 文献对照 |

## 2. 几何计算

### 2.1 基本尺寸

| 量 | 公式 | 出处 |
|---|---|---|
| 小齿轮分度圆 | `d1 = m·z1` | 标准 |
| 小齿轮基圆 | `db1 = d1·cosα` | 标准 |
| 小齿轮齿顶圆 | `da1 = m(z1 + 2ha* + 2x1)` | GB/T 1356 |
| 小齿轮齿根圆 | `df1 = m(z1 - 2ha* - 2c* + 2x1)` | GB/T 1356 |
| 面齿轮分度圆半径 | `r_fp = m·z2/2` | 刘新胜 2.2.2 节 |
| 变位系数为零处 | 同上（连续变位圆柱齿轮的叠加） | 刘新胜 2.2.2 节 |

面齿轮可看作**一系列连续变位的渐开线圆柱齿轮沿齿宽方向叠加**，内端负变位
（趋向根切）、外端正变位（趋向齿顶尖化），中间存在变位为零的截面。

### 2.2 端面重合度

采用何飞(2023) 式(26)(27)：

$$
\varepsilon = \frac{\theta_{a1} N_1 \sin\alpha\cos\alpha - (N_1 - 2 - N_1\cos^2\alpha)}{2\pi \sin\alpha\cos\alpha},
\qquad \theta_{a1} = \frac{\sqrt{r_{a1}^2 - r_{b1}^2}}{r_{b1}}
$$

其中 `N_1 - 2` 项体现"小齿轮比插齿刀少 2 个齿"这一面齿轮传动的固有特征。

### 2.3 内外半径极限（**估算值**）

* 外半径（齿顶尖化）：`r_o ≈ r_fp · sin γ`（刘新胜式(2-3) 的保守简化）
* 内半径（齿根根切）：`r_i ≈ (m·zs/2)·cosα·sinγ`（Litvin 根切条件的工程近似）

> **重要**：精确的根切/尖化极限需要求解插齿刀齿面与面齿轮齿面的展成界限
> 方程（靳广虎 2012 式(2-22)、式(2-24)），涉及三维齿面方程与数值迭代，
> 本项目未实现。软件给出的是工程近似，仅用于判断"用户给定半径是否大致
> 合理"，**不能作为设计定论**。

## 3. 载荷与载荷系数

### 3.1 名义力

$$
F_t = \frac{2T_1}{d_1}, \qquad F_n = \frac{F_t}{\cos\alpha}
$$

功率与扭矩换算：`T[N·m] = 9550·P[kW]/n[r/min]`。

### 3.2 载荷系数（ISO 6336-1 工程简化）

| 系数 | 简化式 | 说明 |
|---|---|---|
| `K_A` | 平稳 1.0 / 冲击 1.25 | 可直接覆盖 |
| `K_V` | `(1 + (v/25)^1.6)·(1 + 0.03(q-7))`，封顶 1.8 | `q` 为精度等级（数字越大精度越低） |
| `K_Hβ` | `1 + 0.35·max(0, b/d1 - 0.5) + 0.02(q-7)` | 齿向分布 |
| `K_Fβ` | `K_Hβ^0.85` | ISO 6336-1 的近似关系 |
| `K_Hα`, `K_Fα` | 1.0 | 直齿面齿轮的齿间分配影响并入 Z_ε / Y_ε |

> 这些是**初步设计用的经验估算**。详细设计应通过 `--KA/--KV/--KHb/--KHa`
> 或 `LoadFactors(...)` 直接给定精确值。

## 4. 接触应力

### 4.1 主引擎：ISO 6336-2

$$
\sigma_{H0} = Z_H Z_E Z_\varepsilon Z_\beta
\sqrt{\frac{F_t}{b\,d_1}\cdot\frac{u+1}{u}},
\qquad
\sigma_H = \sigma_{H0}\sqrt{K_A K_V K_{H\beta} K_{H\alpha}}
$$

| 系数 | 公式 | 值（α=25°, 钢-钢） |
|---|---|---|
| `Z_H` | `√(2/(cosα·sinα))` | 2.285 |
| `Z_E` | `√(1/[π((1-ν₁²)/E₁ + (1-ν₂²)/E₂)])` | 191.6 √MPa（E=210 GPa）|
| `Z_ε` | `√((4-ε_α)/3)`（ε≤2）；`1/√ε_α`（ε>2） | 0.903 |
| `Z_β` | 1（直齿） | 1 |

`Z_E` 注意：ISO 的 `Z_E` **包含** `1/π`。手册常见的 189.8 √MPa 对应
`E = 206 GPa` 的旧约定；用 210 GPa 算得 191.6 √MPa。二者都对，取决于材料
弹性模量的取值约定。

### 4.2 面齿轮接触修正系数 `K_Hface`

当量齿轮法假设载荷沿全齿宽均布。但面齿轮的**接触迹线沿齿宽方向集中**
（接触椭圆长轴远小于齿宽），局部接触应力高于全齿宽平均值。

何飞(2023) 表 1 算例（b=80 mm）对比：

| 量 | 数值 |
|---|---|
| 本软件当量齿轮法（名义） | 535.6 MPa |
| 论文有限元 | 823.2 MPa |
| 比值 | 1.537 |

取 `K_Hface = 1.45`（略保守），修正后 776~841 MPa，与论文偏差 +2.2%。

> **这是经验修正系数，不是普适常数。** 其依据是单篇文献算例的有限元对比。
> 换传动比、齿宽、材料时应重新评估。软件中可调（`solve(K_Hface=...)`）。

### 4.3 参考引擎：Hertz 点接触

用何飞(2023) 式(3)(5)(6) 的面齿轮主曲率（节锥面 θ_s = tanα），配合赫兹
点接触公式：

$$
a = \alpha_c\sqrt[3]{\frac{3F Z_E}{2\Sigma\rho}},\quad
b = \beta_c\sqrt[3]{\cdots},\quad
p_0 = \frac{3F}{2\pi a b}
$$

椭圆系数 `α_c, β_c` 由曲率比 `B/A` 反解偏心率 `e` 后，通过第一/二类完全椭圆
积分求得（`_solve_eccentricity` + AGM/级数实现）。

本引擎给出**单对齿承担全部载荷**时的局部赫兹应力，是**上限参考**，通常
显著高于 ISO 值（本算例 2227 MPa）。

### 4.4 何飞(2023) 简化公式（原样复现）

$$
\sigma_c = \sqrt[3]{\frac{12T_1A^2}{m^3 Z_E^2 N_1\cos\alpha}}\cdot
\frac{1}{\pi\alpha_c\beta\varepsilon}
$$

**关于该公式的重要说明**

论文报告对表 1 算例给出 `σ_c = 660.3 MPa`。我们逐项核对：

1. 公式分母确实是 `Z_E²`（不是 `Z_E`），这样量纲才正确（MPa³→∛→MPa）；
2. 按论文式(27) 算得 `ε = 1.554`；
3. 但用该 `ε` 代入式(32) 得 1524 MPa，与论文的 660.3 MPa 相差 2.3 倍；
4. 若强行取 `ε ≈ 3.6`，则可复现 660.3 MPa——说明原论文式(27) 与式(32)(33)
   之间存在**数值不自洽**。

本软件**如实保留原公式结构并标注** `consistency_note`，不修改公式去凑结果。

## 5. 弯曲应力

### 5.1 主引擎：ISO 6336-3

$$
\sigma_{F0} = \frac{F_t}{b\,m}\,Y_F Y_S Y_\beta Y_\varepsilon,
\qquad
\sigma_F = \sigma_{F0} K_A K_V K_{F\beta} K_{F\alpha}
$$

| 系数 | 公式 | 出处 |
|---|---|---|
| `Y_F` | `6(h_Fe/m)cosα_Fen / [(S_Fn/m)²cosα_n]` | 刘新胜式(3-31) / ISO 6336-3 |
| `Y_S` | `(1.2+0.13L)·q_s^(1/(1.21+2.3/L))`，`L=S_Fn/h_Fe`，`q_s=S_Fn/(2ρ_f)` | 刘新胜式(3-43)~(3-45) |
| `Y_ε` | `0.25 + 0.75/ε_αn` | 刘新胜式(3-46) |
| `Y_β` | `1 - ε_β·β/120°`（直齿 = 1） | 刘新胜式(3-47)(3-48) |

**`Y_F` / `Y_S` 的实现取舍**

精确求 `Y_F` 需要：

1. 用齿条刀具滚切生成齿根过渡曲线（包络）；
2. 用 30° 切线法确定危险截面，求 `S_Fn`、`h_Fe`。

本项目的初版曾实现数值滚切包络，但数值稳定性不足（包络点提取对刀具圆角
参数化与坐标变换极敏感，30° 切点求解易落入错误分支），最终改用**工程近似式**：

```
Y_F ≈ (1.646 + 9.41/z)·(1 - 0.15·(α-20°)/10°)·(1 - 0.12x)
Y_S ≈ (1.682 + 3.82/z)·(1 - 0.05x)
```

在 `z∈[12,100]`、`α∈[20°,30°]`、`x=0` 范围内与 ISO 6336-3 图 11~14 偏差约 ±5%。

> **定型设计请查图并通过 `--YF/--YS` 传入。** 这也是工程软件的常规做法。

### 5.2 面齿轮弯曲应力与当量值的关系

对何飞表 1 算例（b=80 mm），本软件名义弯曲应力 **88.4 MPa**，论文解析模型
**85.8 MPa**，偏差 +3.0%。说明对弯曲应力而言，当量齿轮法（按全齿宽）已经
足够准确，不需要额外修正。

> 这与接触应力形成对比（后者需 ×1.45），原因：接触应力由局部接触决定
> （接触区窄），弯曲应力由整个齿根截面决定（全齿宽参与）。

### 5.3 轮体柔度问题

`GB/T 3480` 的弯曲公式前提是「**轮缘厚度 ≥ 3.5·m_n**」的刚性轮缘。面齿轮是
**薄盘轮体**，该前提不满足——轮缘柔度会使齿根实际应力高于计算值。

软件提供 `K_face`（默认 1.0），建议做轮体柔度评估时取 1.1~1.4，并用有限元复核。

## 6. 强度校核

$$
S_H = \frac{\sigma_{H,lim}\,Z_{NT}Z_LZ_VZ_RZ_WZ_X}{\sigma_H},
\qquad
S_F = \frac{\sigma_{F,lim}\,Y_{ST}Y_{NT}Y_{\delta relT}Y_{RrelT}Y_X}{\sigma_F}
$$

简化假设（可在 `rating.py` 中看到）：

* `Z_L=Z_V=Z_R=Z_W=1.0`（良好润滑、中等速度、Ra ≤ 0.8 μm）
* `Z_X=Y_X=1.0`（模数量级 ≤ 5 mm）
* `Y_δrelT=Y_RrelT=1.0`
* `Y_ST = 2.0`（单向受载）/ 1.4（对称循环）
* 寿命系数按 `(3e6/N_L)^(1/6)` 提升，上限 1.6

**最小安全系数**按可靠度插值给出建议值：

| 可靠度 | S_H,min | S_F,min |
|---|---|---|
| 0.90 | 1.00 | 1.35 |
| 0.99 | 1.18 | 1.76 |

航空传动建议取 S_H ≥ 1.1~1.3、S_F ≥ 1.6~2.0。
