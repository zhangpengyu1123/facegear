# 05 · 论文算例测试设计（黄金基准、容差、不可用清单）

> 配套数据：`work/benchmarks/cases.json`（50 算例）、`work/benchmarks/coefficients.json`（10 组系数/公式链）、
> 数据字典见 `work/benchmarks/README.md`。
> 本文决定：**哪些论文算例可以当黄金基准、断言什么量、容差给多少、哪些必须放弃**。

---

## 0. 一句话结论

6 篇论文里只有 **1 个算例是"全参数 + 全结果"的教科书级基准**（何飞 2023 五齿模型），
另有 **3 个算例可作高质量基准**（刘新胜 HB/Z84 软件算例、李占平 赫兹 / 弯曲截面算例），
**32 组靳广虎参数算例**适合做参数化回归（容差要大），
**2 个算例只能做量级参考**（任雅丽 317 MPa、何飞算例1/2 缺几何），
**刘慧茹 3 个修形方案**只适合作相对比较，不适合绝对应力断言。

## 2. 分层对拍策略（关键：别一上来就断言应力）

应力值受十几个上游量影响，直接断言 `σ = 919.7` 失败时无法定位。建议按 4 层递进，每层独立测试：

```
L1 输入派生量     b、r_p2、内/外半径、变位系数          ← 纯几何，容差 ±0.5%
L2 中间系数       εan、ε、ZH、ZE、Yε、KFβ、KA、KV       ← 容差 ±1~5%
L3 中间几何       接触椭圆 a,b、SFn、hFe、αF、x 因子     ← 容差 ±3~10%
L4 输出应力       σH、σF、SF                            ← 容差见第 1 节
L5 关系/趋势      单调性、序关系、跨齿宽分布形状          ← 无数值容差，只查符号/序
```

L1、L2 大多**互相独立且可解析验证**，是最有性价比的测试；L4 失败时先看 L1~L3 哪层崩了。

### 具体可断言的上游标量（Tier A 算例）

| 量 | 论文值 | 来源 | 建议断言 |
|---|---|---|---|
| `Z_E`（钢，E=206000） | 189.8 √MPa | 刘新胜式(3-29) | `abs(ZE-189.8)<0.5` |
| 何飞 `ε`（m=6.35,z1=25,α=25°,ha\*=1） | 1.5545 | 式(27) 自算 | ±1% |
| 何飞 `YFa·Ysa` | 2.989 | 由 σb=76.3 反算 | ±3% |

| 李占平 接触椭圆 a(第1点) | 5.8139 mm | 表2.2 | ±3% |

## 3. 容差的推导依据（不是拍的）

| 论文 | 论文自报的"方法 vs 方法"差异 | 推出的容差 |
|---|---|---|
| 何飞 2023 | 解析 vs FEM：σc 11.7%、σb 4.3%；简化 vs FEM：σc 19.7%、σb 7.3% | 断言**论文值本身**时 ±3~5%（公式路径唯一）；若拿 FEM 当基准则须放到 ±20% |
| 靳广虎 2012 | 公式 vs FEM：圆柱平均 5.36%、最大 16.9%；面齿轮最大 18.4% | ±20% |
| 刘新胜 2016 | 理论 vs 试验：1000N 平均 3.40%、2000N 7.11%、3000N 6.63%，单组最大 9.88% | 理论值 ±10%（对 GUI 直读值可用 ±2~3%） |
| 李占平 2018 | 未给解析 vs FEM 误差表（正文只做定性对比） | 按赫兹解数值实现差异给 ±5%（a/b 给 ±3%） |
| 刘慧茹 2022 | 无误差表 | 只能做相对序（Tier B） |

> 经验规则：**断言"论文里由公式算出来的值"用窄容差（±3~5%），断言"论文里的有限元值"用宽容差（±15~20%）**。
> 因为我们的软件也是公式实现，应当先复现公式的算术，而不是去拟合别人的网格。

## 5. 反标定（不要用它来"凑答案"，但要用它定位偏差）

何飞算例的 `YFa / Ysa` 只有图（图4），读图精度 ±0.0005 / ±0.02。若软件的 `σb` 简化值对不上 76.3 MPa，
先用下述反算把 `YFa·Ysa` 定标，再判断是系数问题还是几何问题：

```
YFa·Ysa = σb · b · m² · N1 · ε / (2·T1)
        = 76.3 × 80 × 6.35² × 25 × 1.5545 / (2 × 1.6e6)
        ≈ 2.989            （读图独立得到 2.99，偏差 0.1%）
```

- 若软件算出的 `YFa·Ysa` 与 2.99 差 >5% → 问题在 `YF/YS` 的几何口径（SFn、hFe、αF、30°切线）。
- 若 `YFa·Ysa` 对得上但 `σb` 不对 → 问题在 `b`、`ε`、`T1` 或单位（N·mm vs N·m）。
- 同理 `ε`：若 `ε` 与 1.5545 差 >2%，先查 `ha*`（0.8 → ε≈1.424；1.0 → ε≈1.5545）。

> ⚠️ 反标定只能解释偏差，**不能把容差写成 0%**，也不能为此在软件里加"论文修正系数"。

## 6. 已知陷阱（每条都对应一次真实的踩坑风险）

1. **"内径/外径"其实是半径**：480/560 mm 当直径用 → 量级错。三篇论文交叉验证见 `README.md §2`。
2. **压头静载 ≠ 传动切向力**：刘新胜表5.2、靳广虎表4.8 的"载荷 N"是夹具压头力，不是 `Ft = 2T/d1`。
   把 1000 N 直接代进 `σF = (FtF/(b·mn))·YF·YS` 会得到无意义的数。
3. **FEM 值 ≠ 公式值**：何飞自报 解析/FEM = 1.117（接触）、1.043（弯曲）。用 FEM 值当公式实现的断言基准，会把 ±12% 的模型差异误判成 bug。
4. **云图图例最大值 ≠ 观测齿对值**：何飞图7(a) 的 1373.41 MPa 来自相邻齿对边缘接触。
5. **边缘接触点不可用**：何飞明确说第 1~7、16~20 点无法用这套公式，只有第 8~15 点有效——测试取点时别取错。
6. **何飞式(22) 的 1.12 vs 刘新胜式(3-43) 的 1.21**：同一 ISO 公式，取 1.21。
7. **靳广虎表4.3/4.6 只有一列应力**：本数据集判为有限元值、并用误差表反算"计算值"（`derived: true`），断言时优先用 FEM 列 + 容差 20%。
8. **刘慧茹表4-5 的 ae 初值(0.04) 超出上界(0.01)**，疑为 0.004；用到优化模块时需人工确认。
9. **论文页码 ≠ PDF 页码**：`cases.json` 里 `source.pdf_pages` 是 PDF 文件页（1-based），`outputs_expected.*.page` 也是 PDF 页，便于直接 `pagedump.py page` 复核。
