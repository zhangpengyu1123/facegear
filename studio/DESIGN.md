# FaceGear Studio · 设计规范

> 浅色主题（2026-11 升级档）。三个界面共用本规范，新增页面照此实现。

---

## 1. 色彩

四层语义 token，定义在 `src/style.css` 的 `:root`。**不要在新代码里写死颜色**；
ECharts / three.js 等无法读 CSS 变量的地方，从下表取值。

### 表面层

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#f4f6fa` | 页面底色 |
| `--bg2` | `#eaeff6` | 侧栏/次级区域底 |
| `--panel` | `#ffffff` | 卡片、面板、图表底 |
| `--panel2` | `#f8fafc` | 左侧参数栏底 |
| `--panel3` | `#f1f5f9` | 悬停态、数值徽标底 |

### 线条层

| Token | 值 | 用途 |
|---|---|---|
| `--line` | `#e4e9f1` | 常规分隔线、卡片边框 |
| `--line2` | `#cdd6e2` | 输入框、按钮边框 |

### 文字层

| Token | 值 | 用途 |
|---|---|---|
| `--ink` | `#0f172a` | 主文字、数值 |
| `--dim` | `#475569` | 次要文字、标签 |
| `--dim2` | `#64748b` | 辅助说明、单位、轴标签 |

### 语义色

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#2563eb` | 主色：选中态、滑块、图表主线 |
| `--brand2` | `#1d4ed8` | 主色深：激活文字 |
| `--brand-soft` | `#eff4ff` | 主色浅底：选中按钮背景 |
| `--ok` / `--ok-soft` | `#059669` / `#ecfdf5` | 合格、安全 |
| `--warn` / `--warn-soft` | `#b45309` / `#fffbeb` | 警告、阈值提示 |
| `--bad` / `--bad-soft` | `#dc2626` / `#fef2f2` | 不合格、超限 |
| `--hot` | `#e11d48` | 接触应力标注 |
| `--hot2` | `#d97706` | 弯曲应力标注 |
| `--cool` | `#0891b2` | 面齿轮轴线 |
| `--steel` | `#2563eb` | 结构件强调 |

### 数据可视化专属（硬编码，见 `ChartView.vue` / `ModelView.vue`）

| 用途 | 值 |
|---|---|
| 图表主线 | `#2563eb`，面积渐变 `rgba(37,99,235,.22) → .01` |
| 网格线 | `#eef2f7` |
| 坐标轴 | `#cbd5e1`，刻度文字 `#64748b` |

| 3D 面齿轮齿 / 盘 / 小齿轮 | `0x7aa5d6` / `0x577aa8` / `0xb4cdea` |
| 3D 地面网格 | `0xc3cede` / `0xdfe6ef` |

## 2. 阴影

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-sm` | `0 1px 2px rgba(15,23,42,.05)` | 卡片、按钮静态 |
| `--shadow` | `0 1px 3px rgba(15,23,42,.07), 0 1px 2px rgba(15,23,42,.04)` | 面板 |
| `--shadow-md` | `0 4px 14px rgba(15,23,42,.08)` | 浮层、tooltip |

---

## 3. 字体

| 角色 | 规格 |
|---|---|
| 字体族 | `"Segoe UI", "PingFang SC", "Microsoft YaHei", system-ui` |
| 正文 | 13px / 1.6 |
| 面板小标题 | 11px, 600, `letter-spacing: .14em`, 大写 |
| 指标数值 | `Consolas, "SF Mono", monospace`, 23px, 650, `-0.02em` |
| 参数值徽标 | `Consolas` 12.5px 600 |
| 轴标签 | 10.5px `#64748b` |

数值一律用等宽字体（对齐与扫读）。

---

## 4. 间距与圆角

- 间距阶梯：`4 / 6 / 8 / 10 / 12 / 16 / 18 / 22`（px）
- 面板内边距：卡片 `11px 14px`，侧栏 `16px 18px`
- 圆角：按钮 `7px`，卡片/面板 `9~10px`，小组件 `5~7px`
- 顶栏高度 `54px`，左侧参数栏 `336px`，图表侧栏 `274px`

---

## 5. 组件约定

| 组件 | 规格 |
|---|---|
| 顶栏 Tab | 高度 54，底部 2px 下划线指示激活（`--brand`），激活态字重 600 |
| 按钮 `.btn` | 白底 + `--line2` 边框 + `--shadow-sm`；悬停变 `--panel3`；激活 `.on` 用 `--brand-soft` 底 + `--brand` 边 + `0 0 0 2px` 外发光 |
| 滑块 | 轨道 5px `#e2e8f0`；拇指 15px 白底 + 2px `--brand` 边 + 轻阴影，悬停放大 1.12 |
| 指标卡 | 白底 + `--line` 边框 + `--shadow-sm`；标题 11px 灰，数值 23px 等宽 |
| 进度条 | 轨道 `#edf1f6` 5px；安全态 `#10b981→#0891b2`，超限态 `#f59e0b→#dc2626` |
| 判定条 | 合格 `--ok-soft` / 不合格 `--bad-soft`，等宽字体，含具体数值 |
| 键值行 | 底部 1px `--line` 分隔，键 `--dim`、值 `--ink` 等宽 |

---

## 6. 动效

- 时长：`150~260ms`，缓动 `ease` / `ease-out`
- 允许：颜色、边框、阴影、宽度（进度条）、滑块拇指缩放
- 3D 齿轮转动：`0.35 rad/s × speed`，`ω₁ = ω₂·(z₂/z₁)` 反向
- 遵循 `prefers-reduced-motion` 时可关闭装饰动效

---

## 7. 禁止

- 不在组件里写死颜色（除 ECharts / three.js 配置）
- 不用 `!important`
- 不用页面专属选择器侵入共享组件
- 不新增与现有变量含义重叠的变量
