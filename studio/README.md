# FaceGear Studio

面齿轮设计与分析一体化工作台。**Rust + Tauri 2 + Vue 3 + ECharts + three.js**。

> 与 [`facegear`](../)（Python 库）同源：计算内核是同一套公式的 Rust 移植，默认参数下数值一致
> （σ_H = 841 MPa、σ_F = 92 MPa）。

---

## 单页三区布局

不再是三个页签，一屏内同时看到「参数 → 结果 → 曲线 → 模型」：

```
┌──────────────┬────────────────────────────────────────┐
│              │  KPI 摘要：σH · σF · S_H/S_F · 判定     │
│   参数        ├────────────────────────────────────────┤
│   1/3 宽      │  函数曲线（XY/散点/柱/热力/等高线）      │
│   全高滚动    ├────────────────────────────────────────┤
│              │  3D 模型（面齿轮 + 正交小齿轮，可旋转）  │
└──────────────┴────────────────────────────────────────┘
```

### 左：参数（1/3）

- **课题方向**：正交直齿（完整）· 斜齿 · 非正交 · 偏置 · 弧线齿 · 端曲面 · 修形
- **4 个预设**：直升机 / 减速器 / 轻载 / 极限
- **18 个实时滑块**，按「几何 11 / 工况 3 / 材料 4 / 修正 3」分组，可折叠
- 拖动滑块 → KPI、曲线、3D 模型**同时刷新**

### 右上：KPI + 函数曲线

**KPI 条**：σ_H、σ_F（含利用率色阶：<70% 绿 / 70~90% 琥珀 / >90% 红）、S_H/S_F、合格判定、u/ε/F_t/P 辅助值、「变量 33」按钮（弹出全量变量表）。

**曲线区**：顶部工具条一行放完 X 轴参数、扫描范围、Y 轴变量、5 种图表类型、采样点数、当前值；图表带标题、图例、**许用值红色虚线**、**当前工作点钉标**。

### 右下：3D 模型

three.js 渲染面齿轮（盘 + 径向齿）+ 正交小齿轮，按传动比 `ω₁ = ω₂·(z₂/z₁)` 反向转动。鼠标左键旋转 / 滚轮缩放 / 右键平移，参数变化实时重建几何。左下浮动控制：暂停 / 0.4× / 1× / 2.5× / 线框。

## 运行

### 开发（浏览器预览，无需编译 Rust）

```bash
cd studio
pnpm install
pnpm dev          # http://127.0.0.1:5173
```

浏览器里自动降级为 JS 计算内核（与 Rust 数值一致），三个界面全部可用。

### 桌面应用（Tauri）

```bash
cd studio
pnpm install
pnpm tauri dev        # 首次编译 Rust 依赖较慢（数分钟）
pnpm tauri build      # 出安装包（Windows: .msi / .exe）
```

> **注意**：Windows 保留端口段 1337–1436 被占用，所以 dev 端口用 **5173** 而不是 Tauri 默认的 1420。

## 计算内核

`src-tauri/src/core.rs` 移植自 Python 版 `facegear/`，导出三个命令：

| 命令 | 用途 | 对应界面 |
|---|---|---|
| `solve_cmd` | 单点求解，返回 33 个变量 | 参数输入 |
| `sweep_cmd` | 一维参数扫描 | 折线 / 散点 / 柱状 |
| `sweep2d_cmd` | 二维参数扫描 | 热力 / 等高线 / 3D 曲面 |

公式状态与 Python 版一致（详见 [../docs/04-theory.md](../docs/04-theory.md)）：
**8 个有独立算例验证 · 12 个已知有问题（Hertz 曲率链 + 何飞 σ_c）· 49 个能跑但未独立验证**。

**Hertz 链不在主计算路径上**，主结果（σ_H / σ_F）不受影响。
